The idea

Same drawing.
Same direction.
A different response.

The model reads a vector drawing’s code and a direction, then writes the code that makes it move.

I taught a small open model a handful of motions: rise, turn, grow and fade. The scenes above show how that changes its response to the same input.

Both takes use the same drawing and original prompt. The directions above are shortened for readability. These four scenes are selected from the recorded results; the complete experiment is open to explore.
